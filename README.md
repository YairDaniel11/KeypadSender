# KeypadSender

אפליקציית אנדרואיד (minSdk 19 – Android 4.4, targetSdk 34, בלי AndroidX, ניווט מלא במקשים)
שממירה טקסט עברי שמוקלד בה ללחיצות מקשים בסגנון טלפון ישן, ושולחת אותן לקו טלפוני עם שלוחות.

האפיון המלא: [docs/SPEC.md](docs/SPEC.md)

## שימוש קצר
1. הגדרות: מספר הקו, והמתנות (פסיקים) לפני כל שלב.
2. במסך הראשי: בוחרים שלוחה (1 חיפוש, 2 מוזיקה, 3 מדיה), מקלידים, ולוחצים "שלח".
3. לא בשיחה: האפליקציה מחייגת, לוחצת שלוחה, אחר כך 2 (הקלדה), ואז שולחת את ההקשות ו-`#`.
   כבר בשיחה עם הקו: היא רק שולחת את ההקשות (דורש רוט, או מצב צלילים ניסיוני).

## בנייה
- GitHub Actions / GitLab CI: מריצים בדיקות יחידה ובונים APK (`versionCode` לפי מספר ריצה).
- מקומית: `gradle testDebugUnitTest assembleDebug` (Gradle 8.9, JDK 17).
