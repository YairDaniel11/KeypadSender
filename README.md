# 📟 KeypadSender

אפליקציית אנדרואיד שמאפשרת **להקליד טקסט עברי בנוחות**, ממירה אותו ללחיצות מקשים בסגנון טלפון ישן
(כמו הקלדת SMS בטלפון עם מקשים), ושולחת אותן לקו טלפוני עם שלוחות.

**ניווט מהיר:** [חלק א – למשתמש](#חלק-א--למשתמש) · [חלק ב – תיעוד הקוד](#חלק-ב--תיעוד-הקוד)

# חלק א – למשתמש

## למה זה טוב?
בקווים טלפוניים אינטראקטיביים (מערכות שלוחות) שמקבלים טקסט דרך מקשי הטלפון, צריך ללחוץ כמה פעמים על כל אות.
האפליקציה עושה את זה בשבילך: מקלידים את המילים כרגיל, לוחצים **שלח**, והיא מחייגת, מנווטת בשלוחות ושולחת את ההקשות.

האפליקציה בנויה לניווט **מלא במקשים**, בלי מסך מגע, ולכן מתאימה גם למכשירי מקשים עם אנדרואיד. היא עובדת גם במכשירים רגילים.

## 📥 הורדה
- **הגרסה האחרונה (APK):** https://github.com/YairDaniel11/KeypadSender/releases/latest
- כל הגרסאות: https://github.com/YairDaniel11/KeypadSender/releases

להתקנה צריך לאפשר התקנה ממקורות לא ידועים.

## דרישות
- אנדרואיד **4.4 ומעלה**.
- הרשאות (מתבקשות בפעם הראשונה): חיוג, מצב טלפון, וזיהוי שיחות יוצאות.
- **חיוג עם הרצף והטקסט:** עובד בלי רוט.
- **שליחה בתוך שיחה שכבר מתנהלת:** דורשת **רוט**. בלי רוט יש מצב צלילים דרך הרמקול, והוא ניסיוני.

## מה אפשר לעשות
- המרת עברית להקשות: כל אות לפי המקש שלה ומספר ההקשות. רווח, ספרות ואותיות סופיות מטופלים אוטומטית. תווים שלא נתמכים מוצגים באזהרה.
- חיוג אוטומטי: האפליקציה מחייגת לקו, ממתינה בין השלבים ושולחת.
- שליחה בתוך שיחה קיימת: אם כבר מחוברים לקו, נשלח רק הטקסט.
- הגנה: בשיחה עם מספר אחר האפליקציה לא שולחת, כדי שההקשות לא יגיעו למקום הלא נכון.
- **כפתורי שלוחות שאתה מגדיר (1 עד 9)**, ולכל כפתור:
  - כותרת, למשל `1 חיפוש`.
  - מספר קו משלו (ריק = המספר הכללי).
  - רצף שנשלח לפני הטקסט (מקשים והמתנות).
  - סיומת שנשלחת אחרי הטקסט (ברירת מחדל `#`).
- מפת אותיות מותאמת: לשנות אות או להוסיף אות.
- היסטוריית הקלדה וטיוטה שנשמרת.
- ייצוא וייבוא של ההגדרות דרך הלוח.
- מסך עזרה מובנה, עם תוכן עניינים ומפת ההקשות.

## התחלה מהירה
1. **הגדרות** ← מקלידים את **מספר הקו**.
2. **הגדרות ← הגדרת כפתורי השלוחות** ← בוחרים כמה כפתורים, ולכל אחד כותרת, רצף וסיומת.
3. במסך הראשי בוחרים כפתור, מקלידים טקסט ולוחצים **שלח**.

מה קורה בלחיצה על **שלח**:

| המצב | מה האפליקציה עושה |
|---|---|
| לא בשיחה | מחייגת, שולחת את הרצף של הכפתור, ואז את הטקסט והסיומת |
| בשיחה עם הקו של הכפתור | שולחת רק את הטקסט והסיומת |
| בשיחה עם מספר אחר | לא שולחת, ומציגה הודעה |
| בשיחה עם מספר לא מזוהה | לא שולחת, ומציגה הודעה |

## הרצף: מקשים והמתנות
ברצף ובסיומת:
- ספרה (0-9), `*` ו-`#` = מקש שנלחץ.
- פסיק `,` = המתנה של כ-2 שניות. כך נותנים לקו זמן להשמיע הודעה לפני הלחיצה הבאה.
- כל תו אחר מתעלמים ממנו.

דוגמאות:

| רצף | משמעות |
|---|---|
| `,,,1,,2,,` | מחכים כ-6 שניות, לוחצים 1, מחכים כ-4 שניות, לוחצים 2, מחכים כ-4 שניות, ואז נשלח הטקסט |
| `,,3` | מחכים כ-4 שניות, לוחצים 3, ומיד נשלח הטקסט |
| (ריק) | הטקסט נשלח מיד אחרי החיוג |

אם הקו עונה לאט, מוסיפים פסיקים לפני המקש.

## מפת אותיות מותאמת (מתקדם)
בהגדרות, בשדה מפת האותיות, כל התאמה נכתבת כך: `אות=מקש:כמה הקשות`.
למשל, כדי שהאות ב תישלח כ-5 הקשות על מקש 4:

```
ב=4:5
```

כמה התאמות כותבים עם רווח ביניהן: `ב=4:5 ש=7:2 a=2:1`. התאמה דורסת את ברירת המחדל של אותה אות.

## טבלת ההקשות המקורית

| מקש | אותיות (האות = מספר ההקשות) |
|---|---|
| 2 | ד=1 ה=2 ו=3 |
| 3 | א=1 ב=2 ג=3 |
| 4 | מ=1 נ=3 |
| 5 | י=1 כ=2 ל=4 |
| 6 | ז=1 ח=2 ט=3 |
| 7 | ר=1 ש=2 ת=3 |
| 8 | צ=1 ק=3 |
| 9 | ס=1 ע=2 פ=3 |

תווים מיוחדים:
- רווח = מקש 0, הקשה אחת. הספרה 0 = מקש 0, שתי הקשות.
- הספרה 1 = מקש 1, שתי הקשות. הספרות 2-9 = אותו מקש, חמש הקשות.
- שתי אותיות רצופות על אותו מקש: ביניהן נשלחת הקשה אחת על מקש 1 כמפריד.
- אותיות סופיות (ך ם ן ף ץ) נשלחות כאות הרגילה.
- `#` בסוף = סיום ושליחה.

## העברת הגדרות למכשיר אחר
בחלון הכפתורים: **ייצוא ההגדרות ללוח** מעתיק את כל ההגדרות כטקסט, ו**ייבוא הגדרות מהלוח** טוען אותן במכשיר אחר.
הייבוא מחליף את כל ההגדרות. את "יש רוט" ואת פקודת הרוט צריך להגדיר ידנית (מטעמי בטיחות הן לא מיוצאות).

## אם משהו לא עובד
- נשלח רק המקש הראשון בכל קבוצה: בהגדרות מורידים את **מהירות** ל-1.
- המקשים נשלחים מוקדם מדי: מוסיפים פסיקים לרצף.
- אין שליחה בתוך שיחה: מוודאים שניתנו כל ההרשאות, ובמכשיר עם רוט מסמנים **יש רוט**.
- ההודעה "בשיחה עם מספר אחר" מופיעה כשהמספר בשיחה לא תואם למספר של הכפתור הנבחר. בוחרים את הכפתור של הקו שמדברים איתו, ובודקים את המספר בהגדרות.

# חלק ב – תיעוד הקוד

האפיון המלא והנימוקים: [docs/SPEC.md](docs/SPEC.md). חלק ממנו נכתב לפני הוספת כפתורי השלוחות המותאמים, ולכן ההתנהגות הנוכחית מתוארת כאן.

## נתונים טכניים
- Java, בלי AndroidX. `minSdk 19`, `targetSdk 34`, `compileSdk 34`.
- כל API חדש עטוף בבדיקת גרסה.
- ניווט מלא במקשים: `nextFocus` מפורש במסכים, בלי תלות במגע.
- מקור אמת יחיד להגדרות ולמצב שיחה: `SharedPreferences` (דרך `Prefs`).
- חבילה: `com.meir.keypadsender`.

## מבנה הקוד

מקור: `app/src/main/java/com/meir/keypadsender/`

| קובץ | תפקיד |
|---|---|
| `KeypadEncoder` | המרת טקסט עברי להקשות. מחלקה טהורה (בלי אנדרואיד), נבדקת ב-unit test. תומכת בהתאמות מפה (`parseMap`, `encodeBody`) ובתיאור הטבלה (`describeTable`) |
| `SeqUtil` | רצף בסגנון מחרוזת חיוג: ניקוי (`sanitize`) ופירוק לחלקים עם השהיות (`toScript`). טהורה, נבדקת |
| `Dialer` | בניית מחרוזת חיוג (`מספר + רצף + גוף`) וחיוג עם `ACTION_CALL`, כולל בדיקת מצב טיסה |
| `Prefs` | כל ההגדרות: מספר, רוט, מרווח, הכפתורים (כמות, כותרת, מספר, רצף, סיומת), מפת אותיות, טיוטה והיסטוריה |
| `CallTracker` | מצב השיחה והמספר שמדברים איתו (`IDLE`, `IN_CALL_TARGET`, `IN_CALL_OTHER`, `IN_CALL_UNKNOWN`) |
| `CallReceiver` | receiver סטטי ל-`NEW_OUTGOING_CALL` ול-`PHONE_STATE`, מזין את `CallTracker` |
| `PhoneNumberUtil` | נרמול והשוואת מספרים (קידומת 972, 9 הספרות האחרונות) |
| `InCallSendService` | שירות קצר ששולח הקשות בתוך שיחה (רוט או צלילים), עם wake lock ובדיקות בטיחות |
| `RootShell` | סשן `su` יחיד. כל פקודה חוסמת עד שהסתיימה, כך שהמרווחים דטרמיניסטיים |
| `Injector` / `InjectorClient` | תהליך root קבוע (`app_process`) שמזריק מקשים. מהיר מ-`input keyevent`, ושולח UP מיד אחרי DOWN כדי שלא יתפרש כלחיצה ארוכה |
| `CallScreen` | החזרת מסך השיחה לחזית (`TelecomManager`, `moveTaskToFront`, או רוט) |
| `MainActivity` | מסך ראשי: בונה את כפתורי השלוחות דינמית, תצוגה מקדימה, שליחה |
| `SettingsActivity` | הגדרות כלליות |
| `ExtSettingsActivity` | הגדרת כפתורי השלוחות, וייצוא וייבוא |
| `SettingsPorter` | ייצוא וייבוא JSON דרך הלוח |
| `HelpActivity` | מסך עזרה עם תוכן עניינים וקישורי קפיצה, ומפת הקשות |
| `HistoryActivity` | היסטוריית הקלדה |
| `KeyUtil`, `ThemeUtil`, `PermissionUtil` | עזרים: מקש חזור כמחיקה, ערכות נושא (בהיר וכהה), הרשאות |

## זרימת שליחה
1. `MainActivity.trySend`: מקודדת את הטקסט (`KeypadEncoder.encodeBody`, לפי מפת האותיות). טקסט ריק לא נשלח. הטקסט נשמר בהיסטוריה, וחסרות הרשאות מתבקשות.
2. `doSend` קורא את הכפתור הנבחר ומחשב:
   - מספר: `Prefs.effectiveNumber` (של הכפתור, ואם ריק המספר הכללי).
   - רצף: `Prefs.getExtSeq`. גוף: טקסט מקודד + `Prefs.getExtSuffix`.
3. לפי `CallTracker.status`:
   - **`IDLE`, בלי רוט:** `Dialer.buildDialString` בונה מחרוזת אחת (מספר, רצף, גוף) ושולחת לחיוג. כל פסיק הוא השהיה של כ-2 שניות, והמערכת מבצעת אותה.
   - **`IDLE`, עם רוט:** מחייגים את המספר בלבד, ו-`SeqUtil.toScript` מפרק את הרצף והגוף לחלקים עם השהיות. `InCallSendService.startScripted` שולח כל חלק אחרי ההשהיה שלו, כשהשיחה מתחברת.
   - **`IN_CALL_TARGET`:** נשלח הגוף בלבד, בתנאי שהשיחה עם המספר של הכפתור הנבחר (`CallTracker.activeMatches`).
   - **`IN_CALL_OTHER` / `IN_CALL_UNKNOWN`:** לא שולחים, ומציגים הודעה.

## רצף ההקשות (`SeqUtil`)
- תווים חוקיים: `0-9 * # ,`. כל השאר נמחק ב-`sanitize`.
- פסיק = `SeqUtil.COMMA_MS` (2000 מ"ש).
- ברירת המחדל לכפתור i נגזרת מהערכים הישנים: `defaultSeq(p1, i, p2, 2, p3)`, כלומר `,,,i,,2,,`.
- אם הרצף לא מסתיים בהמתנה, החלק האחרון והגוף מאוחדים לחלק אחד.

## מפת אותיות מותאמת
- פורמט: `אות=מקש:הקשות`, רשומות מופרדות ברווח או בפסיק. רשומות לא תקינות מדולגות.
- ההתאמות מתווספות לטבלת ברירת המחדל או דורסות אותה.
- התוצאה נשמרת במטמון לפי מחרוזת ההגדרה (`parseMap`).

## זיהוי השיחה (`CallTracker`)
אין API ציבורי שנותן את המספר של שיחה פעילה, ולכן:
- `NEW_OUTGOING_CALL` ו-`PHONE_STATE` נקלטים ב-`CallReceiver` ונשמרים ב-`SharedPreferences`.
- בכל שליחה בודקים מול `TelephonyManager.getCallState()` החי.
- `IN_CALL_TARGET` = המספר הפעיל תואם למספר הכללי או למספר של כפתור כלשהו. בנוסף `doSend` בודק התאמה לכפתור הנבחר.
- בגרסאות חדשות מספר שיחה נכנסת עשוי לא להתקבל, ואז המצב `IN_CALL_UNKNOWN` ואין שליחה.

## הרשאות
`CALL_PHONE`, `READ_PHONE_STATE`, `PROCESS_OUTGOING_CALLS`, `WAKE_LOCK`, `GET_TASKS`, `REORDER_TASKS`, `MODIFY_AUDIO_SETTINGS`. מבקשים את כולן מראש, ואם נדחו לא שולחים.

## ייצוא וייבוא
- `SettingsPorter` יוצר ומפענח JSON (`org.json`), גרסה `v: 1`.
- נכלל: מספר כללי, מרווח, מהירות, מפת אותיות, והכפתורים (כותרת, מספר, רצף, סיומת).
- **לא נכלל בכוונה:** "יש רוט" ופקודת הרוט. הפקודה רצה כרוט, ולכן אסור לקבל אותה מטקסט חיצוני.
- הייבוא מאמת הכל לפני כתיבה. כל ערך עובר ניקוי (`SeqUtil.sanitize`, ניקוי מספרים).

## בנייה ובדיקות
- מקומית: `gradle testDebugUnitTest assembleDebug` (Gradle 8.9, JDK 17).
- בדיקות יחידה: `app/src/test/java/com/meir/keypadsender/KeypadEncoderTest.java`. מכסות קידוד, נרמול מספרים, בניית מחרוזת חיוג, `SeqUtil` ומפה מותאמת.

## CI ושחרור (GitHub Actions)
קובץ: `.github/workflows/build.yml`. רץ על כל push ל-`main` (למעט שינויים בקבצי `.md`) ועל pull request:
1. `versionCode` מוחלף במספר הריצה.
2. בדיקות יחידה.
3. פענוח keystore מ-secrets, ובניית APK חתום (`assembleRelease`).
4. העלאת ה-APK כ-artifact, ופרסום ב-**Releases** עם התג `v<מספר ריצה>`.

Secrets נדרשים: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`.

## מגבלות ידועות
- שליחה בתוך שיחה קיימת בלי רוט אינה אמינה (מגבלת פלטפורמה).
- עם רוט, התוצאה תלויה במסך השיחה של המכשיר, ובשם הרכיב שלו (פקודת החזרה למסך השיחה ניתנת לעריכה).
- בחיוג ללא רוט, המרווח בין ההקשות נקבע על ידי המערכת.
- ההמתנות (פסיקים) תלויות בקו וצריך לכוון אותן.
